One design for all four input pages: Journal, Stories, Me, Name
=================================================================

Every page has the same parts, in the same order, and the same two modes.

LAYOUT (top to bottom)
  1. Breadcrumb   where you are; tap a crumb to browse
                    Journal:  Life > 2020s > 2026 > September > Sat, Sep 26
                    Stories:  Life > Homes > Elm St
                    Me:       Me
                    Name:     Names > Luann
  2. Text box (EDIT)   or   ✎ Edit button (READ)
  3. Title        Journal: the date   Stories: subject (or category)   Me/Name: the name
  4. Content
       READ:  the summary — Summary | Outline toggle (Me/Name: the profile)
              then the details, read-only (date / category·years·place / facts)
              then related items (Name/Me: mentions)
       EDIT:  the details as editable fields (date / category-subject-years-place / fact chips)
              photos (Journal, Stories)
  5. Buttons (EDIT only)   [Save]  [Cancel]        Delete — at the very bottom, existing items only

TWO MODES — one rule everywhere
  - Empty (new day, new story, blank Me, undescribed name) opens in EDIT. No Cancel (nothing to go back to).
  - Has content opens in READ with one ✎ Edit button.
  - EDIT shows the full transcript in the box — your own words, editable, to add more or fix.
    New input goes below the earlier text. The box grows as you write.
  - Save  = keep the changes, re-summarize, return to READ.
  - Cancel = throw away changes since you tapped Edit, return to READ.
  - While typing, a draft is kept so nothing is lost if you leave.

SAME LABELS EVERYWHERE
  ✎ Edit · Save · Cancel · 🎤 Dictate · Delete
  Found: names spotted as you write; tap one to open its page.
